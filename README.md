# 🌀 Jujutsu Kaisen — Fan Portfolio Site

> *Cursed Energy Mastery • Domain Expansion • Binding Vow • Innate Technique • Reverse Cursed Technique*

A single-page fan tribute site dedicated to **Jujutsu Kaisen**, covering its seasons, movies, and full character roster — built as a themed portfolio project with a dark, cursed-energy aesthetic.

**🔗 Live Site:** [truelineofficail-hub.github.io/Jujutsu-kaisen-](https://truelineofficail-hub.github.io/Jujutsu-kaisen-/)

---

## 📖 About

*Jujutsu Kaisen* is Gege Akutami's dark fantasy manga, concluded at 271 chapters, following Yuji Itadori's battle against the curse of Ryomen Sukuna. This site presents a fan-made overview of the series — its release timeline, season-by-season breakdown, and an extensive character gallery — as a front-end showcase project.

| Stat | Value |
|---|---|
| 📚 Chapters | 271 |
| 🎬 Episodes | 59+ |
| 📅 Debut Year | 2018 |

---

## ✨ Features

- **🎥 Season & Movie Guide** — Dedicated pages for every season and movie, from Season 1 through the upcoming Season 5 and beyond
- **🔮 Upcoming Releases** — A preview section tracking future seasons and movies (Culling Game arcs, Shinjuku Showdown, and more)
- **🧑‍🤝‍🧑 Character Roster** — A comprehensive gallery of 30+ characters, from protagonists and antagonists to supporting sorcerers and curses
- **🎨 Dark Themed UI** — Custom visual design matching the series' tone, with hero banner, stat counters, and smooth section navigation

## 🚀 Getting Started

Run the project locally:

```bash
# Clone the repository
git clone https://github.com/truelineofficail-hub/Jujutsu-kaisen-.git

# Navigate into the project folder
cd Jujutsu-kaisen-

# Open index.html in your browser
open index.html   # macOS
start index.html  # Windows
```

No build tools or dependencies required — it's a static HTML/CSS site.
